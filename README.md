## 🚀 Example Blueprints for the GoCloud Standard Platform

**Reference architectures and deployment patterns for applications on AWS using the [GoCloud Standard Platform](https://github.com/gocloudLa/terraform-aws-standard-platform).**

Each blueprint is a ready-to-adapt project that combines Standard Platform layers (Project / Workload) with application-specific configuration. Use them as a starting point to deploy the same stack with Terraform/Terragrunt and Standard Platform conventions.

### 📖 Related

## 🏗️ What is the Standard Platform?

The **[AWS Standard Platform](https://github.com/gocloudLa/terraform-aws-standard-platform)** is a production-ready AWS infrastructure platform with five layers:

| Layer | Description |
|-------|-------------|
| **Organization** | AWS Organizations, Identity Center (SSO), S3 backend for Terraform state |
| **Base** | VPC, Route53, CloudMap, SNS |
| **Foundation** | ACM, GitLab Runner, IAM, AWS Backup, SES, VPN, WAF, monitoring |
| **Project** | ALB, ECS, ECR, EKS, RDS, S3, EFS, KMS, etc. |
| **Workload** | Static sites, ECS services, Lambda, Batch jobs, EC2 instances |

Blueprints in this repo typically use **Project** and **Workload**; Base/Foundation may be assumed existing in your account.

## 🚀 Quick start (how to use a blueprint)

1. **Clone** this repo or copy the blueprint folder you need.
2. **Adjust** `gocloud.yaml`: `client`, `company`, `region`, AWS accounts, domains, etc.
3. **Generate** (if using GoCloud CLI): `gocloud config validate` and `gocloud generate`.
4. **Configure AWS SSO** (recommended): `gocloud sso setup` and `gocloud sso login --all`.
5. **Deploy** with Terragrunt: `terragrunt plan --all`, `terragrunt apply --all` (or by environment/layer).

Check each blueprint’s `README.md` and `BLUEPRINT.md` for prerequisites and details.

## 📁 Blueprint structure

```
<blueprint-name>/
├── gocloud.yaml          # GoCloud CLI configuration
├── root.hcl              # Terragrunt root (generated)
├── README.md             # Project usage (generated by gocloud)
├── BLUEPRINT.md          # Application-specific docs (manual)
├── project/<project>/<env>/
│   ├── main.tf           # Project module (ECS, RDS, ALB, etc.)
│   ├── metadata.tf
│   ├── backend.tf
│   └── terragrunt.hcl
└── workload/<workload>/<env>/
    ├── main.tf           # Workload module (ECS service, etc.)
    ├── metadata.tf
    ├── backend.tf
    └── terragrunt.hcl
```
